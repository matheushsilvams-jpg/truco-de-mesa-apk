# Truco de Mesa — APK Android

Área pública de distribuição gratuita para os amigos. Este repositório contém somente instaladores e instruções.

## Beta 0.4.0-beta1

Esta beta é instalada como **Truco de Mesa Beta**, separadamente da versão offline anterior. Não desinstale o jogo antigo: ele mantém suas partidas e seu perfil.

O fluxo **Com amigos** já foi implementado e testado em rede local. **O servidor público ainda aguarda a conexão da hospedagem ao repositório privado.** Até isso ser concluído, esta distribuição permite treino offline e conexão manual a um servidor compatível publicado pelo proprietário.

Android 7.0 ou superior, processador ARM64. Baixe o APK na seção Releases e abra o arquivo para instalar. Se o Android pedir autorização, permita a instalação pelo aplicativo utilizado para abrir o APK.

Os códigos-fonte e a chave de assinatura não são publicados aqui.
